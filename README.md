A project started to both get me significantly more familiarized with C and help me learn about game network programming.

Of note, this project includes:
* Authoritative server networking, including client side prediction/reconciliation and interpolation
* A basic ECS
* A proxy application which introduces network latency
* A UTF-8 chat system
* Many cut corners where I wasn't particularly interested in diving in yet

Video of a recent playtest: https://www.youtube.com/watch?v=9bdDQmXsDlI

Dependencies:
* SDL3/SDL3_image/SDL3_ttf
* ENet
* Clay
